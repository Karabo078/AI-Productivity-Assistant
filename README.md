# AI Productivity Assistant

## Project Overview

The **AI Productivity Assistant** is a student portfolio project that demonstrates how generative AI and prompt engineering can be applied to common workplace tasks.

The project focuses on five practical areas:

- Email generation
- Meeting summarization
- Task planning
- Research assistance
- Workplace chatbot interaction

## Project Goals

The goal is to demonstrate how AI can help users work more efficiently while maintaining human oversight and responsible use.

## Features

### 1. Email Generator
Converts a short description into a structured professional email.

### 2. Meeting Summary
Transforms meeting notes into a summary, decisions, action items, and follow-up suggestions.

### 3. Task Planner
Breaks a larger goal into practical steps and provides a suggested priority.

### 4. Research Assistant
Creates research questions and suggests useful source categories.

### 5. Workplace Chatbot
Provides basic productivity guidance based on a user's question.

## Prompt Engineering Approach

The project demonstrates a structured prompt framework:

1. **Role** — define what the AI should act as.
2. **Context** — provide relevant background.
3. **Task** — clearly explain what needs to be done.
4. **Constraints** — specify tone, length, audience, or format.
5. **Output** — define the desired structure of the response.

## Responsible AI

Responsible AI is an important part of this project.

Users should:

- Avoid entering confidential or sensitive information into public AI systems.
- Verify important AI-generated information.
- Check outputs for bias or misleading claims.
- Keep a human responsible for final decisions.
- Use AI as an assistant rather than blindly accepting its output.

## Important Note

The current website contains browser-based demonstrations and does **not** connect to a live external AI API. This keeps the portfolio safe to deploy publicly without exposing an API key.

A future version could connect these interfaces to an approved AI API through a secure backend.

## How to Run Locally
